# Security policy

## Supported versions

| Editrix | Craft CMS | Supported |
| --- | --- | --- |
| 2.0.x | 5 | Yes |
| 1.2.x | 4 | Yes |

## Reporting a vulnerability

Do not open a public issue for a security problem.

Send the details to `editrix-support@thebrandindustry.com`, or use the **Report a vulnerability** button on the Security tab of this repository. Include the Editrix and Craft versions, the steps to reproduce, and what an attacker could do.

A fix ships as a patch release on each supported line, and the release notes name the fixed version.
